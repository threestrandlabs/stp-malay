# Belajar Bahasa Melayu

A static study tool for a Malay class, built for use on phones during the week between classes. Flashcards, a quiz, conversation practice, and a searchable glossary — all driven by one JSON file of vocabulary and dialogues.

No build step, no framework, no npm dependencies, no CDNs. Plain HTML, CSS, and vanilla JS, with self-hosted fonts (no external font requests).

## Running locally

```sh
python3 -m http.server 8814
```

Then open http://localhost:8814/ in a browser. Any static file server works; the app only needs to fetch `data/stp-malay.json` and `data/topic-groups.json` over HTTP (it won't load via `file://`).

## Data

Vocabulary and conversations live in `data/stp-malay.json`, grouped into sets (Week 1–6 and a House Visit Guide). Each card has a topic, Malay term, English translation, an optional usage note, and example sentences. Each conversation has dialogue lines and comprehension questions. Edit this file to add or correct content — the app reads it as-is and needs no rebuild.

`data/topic-groups.json` maps every card topic into 8 parent groups, used to group the topic picker in Flashcards and Quiz setup.

## Files

- `index.html` — page shell and inline icon templates
- `css/style.css` — all styling
- `js/app.js` — app logic (data loading, rendering, state)
- `fonts/` — self-hosted Instrument Sans and Newsreader (SIL Open Font License) plus `fonts.css`
- `data/stp-malay.json` — vocabulary and conversation data (not generated by this app)
- `data/topic-groups.json` — topic-to-group mapping for the grouped topic picker
